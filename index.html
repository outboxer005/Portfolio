AI · MULTI-AGENT · DESKTOP ↗

ZapFix — Autonomous Multi-Agent Platform

An on-device software assistant packaged as a native desktop app. Instead of a single monolithic prompt, ZapFix routes a task through a graph of specialised agents — a planner, a retriever, a code/tool executor, and a critic — that hand off state until the task closes.

  • Agentic RAG with contextual retrieval & dynamic workflow routing, cutting hallucinations vs. a flat prompt baseline.
  • Reasoning-chain dashboard — React UI visualises every agent hop, tool call, and intermediate state so failures are debuggable, not opaque.
  • Cross-platform native shell — Tauri + Bun for a ~15MB binary that runs on Windows / macOS / Linux with system-level tool access.
  • Built the evaluation loop myself: prompt-eval harness, regression seeds, and pass-rate metrics tracked over time.

AI · OCR · NLP ↗

AI Automated Grading System

Grades handwritten answer sheets automatically. Tesseract extracts the handwriting, an NLP scoring pipeline compares against a reference answer key using semantic similarity + rubric weights, and results flow through a Flask + Spring hybrid API.

  • OCR front-end — Tesseract with pre-processing (deskew, denoise) tuned for student handwriting.
  • Scoring engine — cosine similarity on sentence embeddings + keyword rubric, tunable per question.
  • Two-tier serving — Flask for the ML inference, Spring for auth & persistence — so the ML box can scale independently.
  • Cuts hours of manual grading down to minutes for objective/short-answer papers.
