01 / DISTRIBUTED SYSTEMS · COLLABORATIVE PROJECT

Distributed System Monitoring
& Incident Analysis Platform

Explore source ↗

Many computers. Repeated alerts. One place to understand what happened — and what to investigate next.

ILLUSTRATIVE DEMO · NOT CONNECTED TO DEVICESSelect a node to explore
Telemetry & incident flowProposed command / feedback path
SELECTED / CONTROLLER

One controller, a shared operational picture.

The central FastAPI service aggregates telemetry and exposes device status, metrics and incident updates through REST APIs and WebSockets. JWT authenticates users; a configured API key authenticates agents.

The architecture

Python psutil agents collect CPU, memory, disk, network, process and host telemetry from multiple computers. A central FastAPI controller stores data with PostgreSQL, SQLAlchemy and Alembic, then publishes status and incident updates.

Configurable sampling and bounded retries keep collection resilient. Repeated-breach filtering, alert deduplication, severity escalation and correlation turn recurring signals into incident workflows.

Analysis without blocking ingestion

Asynchronous RAG retrieves runbooks and historical incident resolutions. LLM work runs in background tasks outside the ingestion response path. User authentication uses JWT; agent authentication uses API keys when configured.

My contribution

Developed collaboratively with a friend. I built the AI and execution workflows using LangGraph, LangChain and LLM orchestration. This contribution is owner-reported; the linked source documents the shared monitoring platform.

Implementation status

IN PUBLIC SOURCE Telemetry, persistence, REST/WebSockets, incident workflows and optional background RAG.

INTEGRATION DIRECTION ZapFix desktop/terminal agents for remote commands and execution status/feedback. This owner-described integration is not yet evidenced in the linked source.

Retry note: the README describes exponential backoff; the current telemetry agent code uses a linear retry delay. No scale or performance benchmarks are claimed.
